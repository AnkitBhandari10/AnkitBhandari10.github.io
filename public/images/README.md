# Images

Drop photos and screenshots in this folder with these exact names and they appear on the site automatically.
Until a file exists, the site shows a soft placeholder in its spot.

| File name | Where it shows |
|---|---|
| `gallery-1.jpg` | Large photo at the top of the gallery beside "About me" (landscape works best) |
| `gallery-2.jpg`, `gallery-3.jpg` | Two square photos under it |
| `flockwork.png` | Thumbnail on the Flockwork project bar |
| `flashidex.png` | Thumbnail on the Flashidex project bar |
| `portfolio.png` | Thumbnail on the Portfolio project bar |

To change a file name or caption, edit `src/components/sections/About.jsx` (gallery) or `src/components/sections/Projects.jsx` (projects).
Your resume goes one level up, at `public/resume.pdf`.
